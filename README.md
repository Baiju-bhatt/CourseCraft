
# CourseCraft | AI-Powered Course Content Generator

**Live Application:** [Launch CourseCraft](https://responsible-vitality-production-f213.up.railway.app/)

**CourseCraft** is an AI-driven learning platform designed to transform traditional, one-size-fits-all education into a **personalized and adaptive learning experience**.

By leveraging **Large Language Models (LLMs)** and intelligent prompt engineering, CourseCraft dynamically generates structured courses, learning materials, and assessments tailored to individual knowledge levels, learning goals, and preferred study durations.

## Key Features

- **AI-Powered Course Generation:** Automatically creates structured course content and assessments using generative AI.

- **Assessment-Driven Personalization:** Identifies existing knowledge and learning gaps to generate targeted learning paths.

- **Adaptive Learning:** Tailors educational content to individual proficiency levels and learning requirements.

- **Interactive AI Assistant:** Provides contextual explanations, answers questions, and supports learners throughout their courses.

- **Flexible Learning Experience:** Supports customizable course durations, interactive quizzes, hands-on practice, and additional learning tools.

## Technology Stack

| Category | Technologies |
|----------|-------------|
| **Frontend** | React, JavaScript |
| **Backend** | Python, Flask, REST APIs |
| **AI / LLMs** | Mistral-7B-Instruct, Phi-3-Mini, Llama-3.2 |
| **AI Integration** | Hugging Face Inference API |
| **Database** | SQLite, PostgreSQL |
| **Authentication** | Flask-Login |

## Project Objective

To make **personalized, high-quality learning more accessible** through intelligent content generation, assessment-driven customization, and adaptive learning pathways.

CourseCraft aims to bridge the gap between static educational content and the evolving needs of individual learners, creating a more **flexible, interactive, and learner-centric educational experience**.
